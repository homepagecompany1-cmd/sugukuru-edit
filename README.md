# すぐ来る 動画編集キット

スマホで撮った動画を、**あなたの AI（Claude Code / Codex）が、型どおりに自動で編集**します。PC はいりません。

- ジャンプカット（無音を切る）・ズーム・字幕（白太字＋黒縁）
- 話題の札・冒頭の見出し・名前の札・結論の白い箱・感情の一言・黒い札（手順）・画面録画の2分割
- 縦（型1）と横（型2〜6）

## 使い方（スマホだけ）

**はじめての1回**
1. このページ右上の **「Use this template」** → 自分の GitHub にコピー
2. スマホで [claude.ai/code](https://claude.ai/code) を開き、コピーしたリポジトリを選ぶ
3. 環境の設定 → ネットワーク → 許可するドメインに **`up.yoseca.com`** を足す

**毎回**
1. [up.yoseca.com](https://up.yoseca.com/) で型を選んで、動画を上げる
2. 出てきた文をコピーして、Claude Code に貼る
3. 終わると、できあがりのページ（`up.yoseca.com/r/…`）に届く → スマホに保存

上げた動画と完成した動画は **7日で自動で消えます**。

## 型

| 番号 | 型 | 向き |
|---|---|---|
| 1 | 縦で答える（上に顔写真と題・黒い帯に話題） | 縦 |
| 2 | 対談 | 横 |
| 3 | 時刻ごとに話す（1日の流れ・工程） | 横 |
| 4 | 年表・自己紹介 | 横 |
| 5 | 黒い札で手順を見せる | 横 |
| 6 | 画面を見せながら話す | 横 |

型の見た目（文字の大きさ・位置・色・ズーム・無音の切り方）は `kata/<番号>_*/型.json` で変えられます。

## PC で使う時
```
bash setup.sh
bash tools/edit.sh 2 ~/Movies/撮った動画.mov
```
AI に「計画.json を書いて」と頼む所があります（終了コード 3）。詳しくは `CLAUDE.md`。
